1. Drag Artemis into Applications

    Open the file you downloaded, then drag Artemis onto the Applications folder.

  2. Open Artemis

    macOS stops it the first time, because this build isn’t checked by Apple yet. Click Done.

  3. Allow it in System Settings

    Open Privacy & Security, scroll down to Security and click Open Anyway next to Artemis.

  4. Confirm, and you’re in

    Click Open Anyway once more, then use Touch ID or your password. Artemis opens.
