Artemis is downloading.

If it doesn’t start, download it here. Then follow these four steps. You only do this once.

  1. Drag Artemis into Applications

    Open the file you downloaded, then drag Artemis onto the Applications folder.

  2. Open Artemis

    macOS stops it the first time, because this alpha isn’t checked by Apple yet. Click Done.

  3. Allow it in System Settings

    Open Privacy & Security, scroll down to Security and click Open Anyway next to Artemis.

  4. Confirm, and you’re in

    Click Open Anyway once more and use Touch ID or your password. Artemis opens.
