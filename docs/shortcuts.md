# Keyboard shortcuts

The menu bar's shortcuts, menu by menu, as `Artemis/ArtemisApp.swift` binds them. Each one sits beside its item in the menu, so the menu bar is the reference when this page and the app disagree.

## File

| Shortcut | Action                                                                 |
| -------- | ---------------------------------------------------------------------- |
| ⌘T       | New Tab… (the command bar: finds tabs in every space, plus favourites) |
| ⌘N       | New Window                                                             |
| ⌘W       | Close Tab, or Close Window when there's no tab                         |
| ⌘⇧W      | Close Window, while ⌘W closes a tab                                    |
| ⌘⇧T      | Reopen Closed Tab (or Folder)                                          |
| ⌘D       | Pin / Unpin Tab                                                        |
| ⌘⇧K      | Clear Today's Tabs                                                     |
| ⌥⌘N      | Open Anything… (also works while Artemis is in the background)         |
| ⌘O       | Open File…                                                             |
| ⌘⇧C      | Copy Page Link                                                         |
| ⌥⌘⇧C     | Copy Page Link as Markdown                                             |
| ⌘L       | Open Location…                                                         |
| ⌘F       | Find…                                                                  |
| ⌘G / ⌘⇧G | Find Next / Find Previous                                              |
| ⌥⌘F      | Ask About This Page…                                                   |
| ⌘P       | Print…                                                                 |

## Edit

| Shortcut  | Action                                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| ⌘Z / ⌘⇧Z  | Undo / Redo the last sidebar action, the typing in a focused field or page, or in Settings the last change |

## View

| Shortcut             | Action                                                |
| -------------------- | ----------------------------------------------------- |
| ⌘+ (or ⌘=) / ⌘− / ⌘0 | Zoom In / Zoom Out / Actual Size, remembered per site |
| ⌘⇧R                  | Show / Hide Reader                                    |
| ⌥⌘⇧T                 | Translate Selection…                                  |
| ⌥⌘T                  | Translate Page / Show Original                        |
| ⌘⇧M                  | Mute / Unmute Tab                                     |
| ⌘S                   | Show / Hide Sidebar                                   |
| ⌘⇧D                  | Show / Hide Toolbar                                   |
| ⌥⌘V                  | Split View / Unsplit                                  |
| ⌃⇧+ / ⌃⇧−            | Add Split Pane / Close Split Pane                     |
| ⌥⌘] / ⌥⌘[            | Focus Next Pane / Focus Previous Pane                 |
| ⌃⇧1–⌃⇧4              | Focus Pane 1–4                                        |
| ⌘⇧P                  | Picture in Picture                                    |
| ⌥⌘I or F12           | Show / Close Web Inspector                            |
| ⌘E                   | Next Extension (cycles the pinned extensions)         |

## Navigate

| Shortcut   | Action                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| ⌘R         | Reload Page                                                                                          |
| ⌥⌘R        | Reload From Origin                                                                                   |
| ⌘[ or ⌘←   | Back                                                                                                 |
| ⌘] or ⌘→   | Forward                                                                                              |
| ⌘⇧] or ⌥⌘↓ | Next Tab                                                                                             |
| ⌘⇧[ or ⌥⌘↑ | Previous Tab                                                                                         |
| ⌃⇥         | Recent Tab. Hold ⌃ to see recent tabs: ⇥ and ⇧⇥ step, letting go switches, Esc cancels               |
| ⌃⇧⇥        | Tab Before Last                                                                                      |
| ⌘Y         | History                                                                                              |
| ⌘⇧Y        | Archive                                                                                              |
| ⌘⇧J        | Downloads                                                                                            |
| ⌘⇧L        | Library                                                                                              |
| ⌘1–⌘8      | Go to Tab: the sidebar's rows, favourites first. While the command bar is open, ⌘1–⌘4 pick its scope |

## Spaces

| Shortcut  | Action                                       |
| --------- | -------------------------------------------- |
| ⌘⇧E       | New Space…                                   |
| ⌘⇧N       | New Incognito Window                         |
| ⌥⌘← / ⌥⌘→ | Previous Space / Next Space                  |
| ⌃1–⌃9     | The first nine spaces, in sidebar order      |
| Hold ⌃    | Number the space dots, to see which is which |

## Mouse and trackpad

| Gesture                                 | Action                                                                                                                               |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Two-finger swipe                        | Move between spaces (past the last one opens the Library)                                                                            |
| ⌘-click (or middle-click) a link        | Open in a background tab                                                                                                             |
| ⇧⌘-click a link                         | Open in a new tab in front                                                                                                           |
| ⇧-click a link                          | Peek: a floating preview over the page                                                                                               |
| ⌥-click a link                          | Open in a split beside the page                                                                                                      |
| ⌥⌘-click a link                         | Open in a Scout window                                                                                                               |
| ⌘-click a tab row                       | Add it to the selection (⇧-click extends the range). Right-click the selection to pin, mute, sleep, move, split or close all of them |
| Drag a tab onto a space icon            | Move it into that space                                                                                                              |
| Drag a tab to a content edge            | Tile it into a split                                                                                                                 |
| Drag a tab onto another tab (and dwell) | Merge them into a split                                                                                                              |
